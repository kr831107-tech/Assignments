# Web Designing Workshop – 18 HTML Assignments

Welcome to the **Web Designing Workshop** repository! This project contains the source code for 18 practical assignments designed to help beginners understand the fundamentals of web development using HTML5 and CSS.

The assignments cover basic HTML page structure to advanced concepts such as accessible web pages, responsive tables, form validation, and a complete student admission page.

## 📚 Assignments Included

| No. | Assignment | Topics Covered |
|---|---|---|
| 01 | HTML Page Structure and Comments | HTML5 structure, comments, basic tags |
| 02 | Headings, Paragraphs and Formatting | Headings, paragraphs, text formatting, entities |
| 03 | Block and Inline Elements | DIV, SPAN, block and inline elements |
| 04 | Semantic and Non-Semantic Elements | Header, nav, main, section, article, div |
| 05 | HTML Lists | Unordered, ordered and description lists |
| 06 | Nested and Mixed Lists | Nested lists and syllabus outline |
| 07 | Navigation Menu Using Lists | Horizontal navigation menu using CSS |
| 08 | Hyperlinks and Images | Internal, external, email and image links |
| 09 | Quotation and Citation Elements | Blockquote, q, cite, abbr and address |
| 10 | HTML Multimedia | Images, audio, video and YouTube embedding |
| 11 | Web Accessibility | ARIA labels, alt text and skip links |
| 12 | HTML Tables | Caption, thead, tbody and tfoot |
| 13 | Rowspan and Colspan | Creating a class timetable |
| 14 | Nested and Responsive Tables | Nested tables and horizontal scrolling |
| 15 | HTML Forms | Input elements, labels and fieldsets |
| 16 | Select, Textarea and Buttons | Dropdowns, textareas and button types |
| 17 | Form Attributes and Validation | Required, pattern, min, max and minlength |
| 18 | Student Admission Mini Project | Semantic layout, tables and validated forms |

## 🛠️ Technologies Used

- **HTML5** – Webpage structure and content.
- **CSS3** – Styling and page layouts.
- **Basic JavaScript** – Button interaction.
- **PHP (optional backend)** – Form submission endpoint.

## 💻 Tools Required

- Visual Studio Code
- Google Chrome, Microsoft Edge or Mozilla Firefox
- Live Server VS Code extension (optional)

## 🚀 How to Run the Projects7

1. Open the project folder in Visual Studio Code.

2. Select any assignment HTML file.

3. Open the file in your browser or use the Live Server extension.

4. Explore the output and modify the code to understand how each HTML element works.

## 🎯 Learning Objectives

By completing these assignments, you will gain practical knowledge of:

- Understanding the basic structure of HTML documents.
- Working with HTML tags, attributes and elements.
- Creating navigation menus and hyperlinks.
- Embedding images and multimedia content.
- Designing tables and forms.
- Implementing basic form validation.
- Understanding semantic HTML and accessibility.
- Building a simple student admission webpage.

## ⚠️ Important Note

Assignments 17 and 18 use `submit.php` as the form submission endpoint. Client-side HTML validation works in the browser, but actual form submission requires a PHP-enabled server and a suitable `submit.php` handler.
